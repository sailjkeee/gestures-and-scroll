# Жесты и прокрутка

[English version](README.md)

**Gestures & Scroll** — утилита для строки меню macOS. Она позволяет **развернуть прокрутку колеса мыши и сохранить естественную прокрутку на трекпаде**. Касания и свайпы тремя или четырьмя пальцами выполняют выбранные действия. Свою фигуру на встроенном трекпаде можно назначить на запуск приложения или управление окном.

В правом верхнем углу настроек можно выбрать «Язык macOS», English или «Русский». Прокрутку и жесты можно включать отдельно из строки меню. [Скачать DMG для Mac с Apple Silicon](https://github.com/sailjkeee/gestures-and-scroll/releases/latest)

## Как появилась идея

На моём Mac работали две утилиты. Scroll Reverser позволял выбрать разные направления прокрутки для мыши и трекпада. В TrackpadGestureMap я настроил копирование касанием тремя пальцами и вставку четырьмя. Захотелось управлять этим из одного меню и добавить свои фигуры, чтобы, например, открывать Telegram одним движением. Так появилась утилита «Жесты и прокрутка». [Scroll Reverser](https://github.com/pilotmoon/Scroll-Reverser) · [TrackpadGestureMap](https://github.com/turhe123/trackpad-gesture-map)

## Как развернуть прокрутку только у мыши

1. Нажмите значок трекпада в строке меню и откройте **«Настройки…» → «Прокрутка»**.
2. Включите **«Управлять прокруткой»**.
3. Выберите **«Мышь» → «Классическая»** и **«Трекпад» → «Естественная»**. Это начальные настройки утилиты. Колесо мыши будет прокручивать в классическом направлении, трекпад сохранит естественное.

Для каждого устройства можно выбрать один из трёх режимов.

| Режим | Что он делает |
| --- | --- |
| **Естественная** | Прокручивает так же, как трекпад с включённой естественной прокруткой. |
| **Классическая** | Использует привычное для колеса мыши направление, противоположное естественному. |
| **Как в macOS** | Использует системное направление прокрутки для этого устройства. |

Выбранное направление можно применить к горизонтальной прокрутке. Для ступенчатого колеса можно задать постоянное число строк за одно деление.

## Как настроить жесты трекпада

Откройте **«Настройки…» → «Жесты»**, включите **«Жесты трекпада»** и выберите **«3 пальца»** или **«4 пальца»**. В блоке **«Назначения»** задайте действие для касания и свайпов вверх, вниз, влево и вправо. Название распознанного движения появится в строке **«Последний жест»**.

| Жест по умолчанию | Действие |
| --- | --- |
| Касание тремя пальцами | Копировать выделенное |
| Касание четырьмя пальцами | Вставить в активном приложении |
| Свайп вверх четырьмя пальцами | Открыть Mission Control |

Доступны копирование, вставка, вырезание, отмена и повтор, выделение всего, Mission Control, закрытие и сворачивание окна, выход из приложения и вариант **«Без действия»**. Если свайп одновременно вызывает жест macOS, отключите совпадающий свайп в системных настройках трекпада.

## Как записать фигуру и открыть ею приложение

На встроенном трекпаде можно нарисовать крест двумя штрихами в форме X или плюса. По умолчанию крест выполняет **«Выйти из приложения»** для активной программы. Чтобы закрывать только окно, назначьте **«Закрыть окно»**.

1. Включите **«Жесты трекпада»** и откройте **«Настройки…» → «Рисование»**. Включите **«Фигуры одним пальцем»**.
2. Нажмите **«Записать фигуру…»**. Нарисуйте её одним пальцем в один или два штриха и поднимите палец. Дайте фигуре название.
3. Назначьте действие и сохраните фигуру. Для запуска выберите **«Открыть приложение…»** и укажите нужную программу в диалоге macOS.

Например, запишите угол и назначьте ему Telegram. Удерживайте **Control** и повторите фигуру. Если Telegram открыт, он появится на переднем плане. Если закрыт, приложение запустится. В поле **«Клавиша для рисования»** можно выбрать **Option** или **«Без клавиши»**. Чтобы сменить программу, нажмите на её название рядом с фигурой.

## Установка на Mac

Нужен Mac с Apple Silicon и macOS 14 или новее. Откройте DMG, перетащите **Gestures and Scroll.app** в «Программы» и запустите оттуда. [Последний релиз и DMG](https://github.com/sailjkeee/gestures-and-scroll/releases/latest)

Сборка подписана локально (ad hoc). Если macOS заблокирует первый запуск и вы доверяете файлу из релиза, разрешите открытие приложения через **«Системные настройки» → «Конфиденциальность и безопасность»**. После запуска разрешите утилите доступ в разделе **«Универсальный доступ»**, чтобы она могла менять прокрутку и выполнять сочетания клавиш. [Инструкция Apple по первому запуску](https://support.apple.com/en-us/102445)

## Сборка и проверки

Установите Command Line Tools for Xcode и выполните из каталога проекта следующие команды.

~~~sh
./check.sh
./build.sh
~~~

Утилита появится в **build/Gestures and Scroll.app**. Тесты проверяют сохранение профиля, язык интерфейса, направление прокрутки, распознавание жестов и фигур на тестовых кадрах, назначение приложений и низкоуровневый ввод. GitHub Actions запускает тесты и сборку на Apple Silicon.

Настройки хранятся локально в UserDefaults. Прокрутка обрабатывается через Quartz. Для чтения касаний встроенного трекпада и определения некоторых устройств используются закрытые интерфейсы macOS. После обновлений системы работу этих функций стоит проверить на реальном Mac.

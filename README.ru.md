# Жесты и прокрутка

[English version](README.md)

«Жесты и прокрутка» работает в строке меню macOS. Утилита настраивает направление прокрутки мыши и трекпада по отдельности, выполняет действия по касаниям и свайпам и распознаёт фигуры, нарисованные на встроенном трекпаде. Русский и английский доступны в настройках.

## Открыть приложение фигурой

Через значок в строке меню открой **«Настройки…» → «Рисование»**. Выбери **«Открыть приложение…»** у существующей фигуры или нажми **«Записать фигуру…»** и создай свою. Выбери установленное приложение в диалоге macOS. Чтобы поменять назначение позже, нажми на название выбранного приложения.

Для вызова фигуры удерживай выбранную клавишу. По умолчанию это Control. Если приложение уже запущено, macOS выведет его на передний план.

## Сборка

Проект рассчитан на Mac с Apple Silicon и macOS 14 или новее. Установи Command Line Tools for Xcode и выполни из каталога проекта следующие команды.

~~~sh
./check.sh
./build.sh
~~~

Готовая утилита появится в **build/Gestures and Scroll.app**. Открой её через Finder. Для прокрутки и сочетаний клавиш выдай ей доступ в **«Системные настройки → Конфиденциальность и безопасность»**. В разных версиях macOS нужный раздел называется «Универсальный доступ» или «Управление устройством и доступ к данным».

Тесты проверяют сохранение профиля, логику прокрутки, распознавание на тестовых кадрах и назначение приложений. Проверку реального колеса и трекпада проведи на Mac после выдачи разрешения.

## Публикация исходников

Создай пустой репозиторий GitHub. Из каталога проекта выполни следующие команды, указав адрес своего репозитория.

~~~sh
git init -b main
git add .
git commit -m "Initial public release"
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
~~~

В репозитории есть проверка сборки через GitHub Actions. Локальная сборка подписывается ad hoc. Для распространения готового приложения на другие Mac используй подпись Developer ID и нотарификацию Apple. [Подпись для распространения](https://developer.apple.com/documentation/xcode/creating-distribution-signed-code-for-the-mac/), [Нотарификация](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)

Фигуры на встроенном трекпаде используют закрытый интерфейс macOS. После обновлений системы проверь распознавание на реальном устройстве. Назначения хранятся локально в UserDefaults.
